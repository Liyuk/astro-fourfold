# A Quiet Publication

A static-first personal publication theme for Astro.

It is designed for independent writers, engineers, researchers, and creators who want more than a chronological list of posts. The theme treats a personal website as a small publication with several related content types and reading paths.

## Highlights

- Markdown content collections
- Writing archive with year pages and pagination
- Ordered columns for guided reading
- Cross-content tags
- Project archive with lifecycle status
- Versioned research notes
- Photo essays
- Client-side search with a generated static index
- Local browser favorites
- Light and dark themes
- RSS, sitemap, robots, canonical URLs, Open Graph, and JSON-LD
- GitHub Pages project-subpath support
- GitHub Actions deployment
- No database or server runtime required
- No real author identity embedded in the starter

## Why this project

Most blog starters focus on rendering Markdown and listing recent posts. A Quiet Publication adds an editorial information architecture:

- **Writing** preserves the chronological archive.
- **Columns** provide an intentional reading order.
- **Tags** support lateral exploration.
- **Projects and research** document practice and evidence.
- **Photo essays** support visual work.
- **Start, search, favorites, and RSS** help readers enter and return.

The implementation remains static-first. Build-time code produces pages, feeds, indexes, and metadata. Browser JavaScript is limited to search, theme selection, favorites, and link copying.

## Design system

The visual language uses restrained editorial typography, semantic color tokens, controlled reading widths, and a small built-in SVG icon system. The repository includes screenshots, architecture diagrams, a publishing flow, a feature matrix, and content-schema documentation.
